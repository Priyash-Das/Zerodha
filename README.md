# Zerodha Project

A comprehensive trading platform application with multiple components including backend API, dashboard, and frontend landing pages.

## Project Structure

- **backend/**: Node.js backend with Express server and MongoDB models
- **dashboard/**: React-based trading dashboard application
- **frontend/**: React-based landing pages and marketing website

## Features

### Backend
- RESTful API endpoints
- MongoDB integration with Mongoose
- Models for Holdings, Orders, and Positions
- Data validation schemas

### Dashboard
- Real-time trading data visualization
- Portfolio management
- Order management
- Position tracking
- Interactive charts and graphs

### Frontend
- Modern landing pages
- Product information
- Pricing details
- Team information
- Support and documentation

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- MongoDB
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Priyash-Das/Zerodha.git
cd Zerodha
```

2. Install backend dependencies:
```bash
cd backend
npm install
```

3. Install dashboard dependencies:
```bash
cd ../dashboard
npm install
```

4. Install frontend dependencies:
```bash
cd ../frontend
npm install
```

### Running the Application

1. Start the backend server:
```bash
cd backend
npm start
```

2. Start the dashboard:
```bash
cd dashboard
npm start
```

3. Start the frontend:
```bash
cd frontend
npm start
```

## Technologies Used

- **Backend**: Node.js, Express, MongoDB, Mongoose
- **Dashboard**: React, CSS3, Chart.js
- **Frontend**: React, CSS3, Modern UI/UX
